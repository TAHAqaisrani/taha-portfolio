# 🌐 Taha Khan — Portfolio Website

This is my personal portfolio website built with **React + Tailwind CSS**.
It showcases my skills, projects, and contact information in a clean and modern design.

---

## 🚀 Features

* Responsive design (works on desktop & mobile)
* Smooth navigation between sections
* Highlighted skills and projects
* Contact details with quick links to GitHub & LinkedIn
* Deployed for easy online access

---

## 🛠️ Tech Stack

* **Frontend:** React, Vite
* **Styling:** Tailwind CSS, DaisyUI (for UI components)
* **Icons:** React Icons
